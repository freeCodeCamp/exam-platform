# Apps

This platform consists of the following applications:

| Name                                            | Shorthand | Description                                                                          |
| ----------------------------------------------- | --------- | ------------------------------------------------------------------------------------ |
| [Auth API](./auth-api.md)                       | aAPI      | HTTP REST API for Web App                                                            |
| [Curriculum Database](./curriculum-database.md) | cDb       | Dolt database used by aAPI and eDd                                                   |
| [Desktop App](./desktop-app.md)                 | dApp      | Desktop application that serves exam content and takes candidate input               |
| [Examiner Dashboard](./examiner-dashboard.md)   | eDd       | Admin web application for staff to edit exam content and moderate candidate attempts |
| [Examiner Database](./examiner-database.md)     | eDb       | Postgres database used by aAPI and eDd                                               |
| [Web App](./web-app.md)                         | wApp      | Candidate web application for registration and verification                          |
